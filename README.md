# OSNIT

OSNIT is a public-source intelligence starter page for exploring public web references and public Instagram profile URLs in a privacy-safe way.

## What this page does

- Accepts a username or public-facing name.
- Generates browser links to public Instagram and web-search destinations.
- Keeps the lookup client-side in the browser.
- Helps visitors compare public results without claiming private-profile access.

## What it does not do

- It does not access private Instagram accounts.
- It does not bypass login walls or access controls.
- It does not claim to reveal private or historical account data.
- It does not provide user-targeted data beyond publicly indexed sources the visitor opens.

## Run locally

Open `index.html` in a browser, or serve the folder with a simple static server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Privacy and usage

Use this tool lawfully. Public web indexes can be incomplete, stale, or incorrect. Any external results are governed by the third-party providers you choose to open.

OSNIT is independent and not affiliated with Instagram or Meta.
