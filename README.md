# Beyond Reasons

A simple, ad-free, static directory for public-source research tools. The visitor page is titled **Beyond Reasons** and includes a small **By Zain** corner sticker.

## Run locally

Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Minimal, responsive premium dark UI with no ads.
- Browser-side form creates public Instagram-related search links for Google, Bing, DuckDuckGo, and Yandex.
- External resource cards for Maltego, Sherlock, Holehe, Yandex, TinEye, and Face2Social.
- No backend, scraping, credentials, or query storage.

External services are independent and may change or require their own accounts, installation, or permissions. Holehe checks email-based account registrations; use only for your own email or with clear authorization. This page does not access private profiles, bypass access controls, or retrieve private or complete historical username data. Results from search engines may be stale, incomplete, or inaccurate.

## GitHub Pages URL

This page is ready to publish through GitHub Pages. The current repository URL remains `https://zbinmy.github.io/public-profile-finder/` if Pages is enabled. To get a shorter path, rename the repository to `beyond-reasons`; the URL would then be `https://zbinmy.github.io/beyond-reasons/`. A `BR.github.io` URL would require a GitHub account named `BR` and its user-site repository named `BR.github.io`; changing the page title alone cannot create that domain.

Beyond Reasons is independent and not affiliated with Instagram, Meta, or the listed services.
