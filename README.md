# OpenTrace

A privacy-first, static visitor page for starting research into publicly indexed Instagram profile information.

## Run locally

Open `index.html` in a browser. No build step, dependencies, backend, or API keys are required.

## What it does

- Creates links to an Instagram profile URL and public web-search results for a user-entered handle or name.
- Keeps the query in the browser until a visitor chooses to open a search provider.
- Makes no automated requests, scrapes no pages, and stores no search history.

## Limitations and privacy

This project does **not** access private profiles, bypass Instagram's access controls, reveal non-public data, or promise complete historical username information. Public web indexes can be incomplete, stale, or incorrect. Results are controlled by the external providers visitors choose to open. Use public information lawfully and respect people's privacy.

OpenTrace is independent and is not affiliated with Instagram or Meta.
